# Security

Please don't report security issues in public GitHub issues.

Use [private vulnerability reporting](https://github.com/youssefaltai/docket/security/advisories/new) instead, with what you found and how to reproduce it.

Only the latest `main` is supported. Docket's security model (one shared token, Host checks, HttpOnly cookie) is described in [SPEC.md](SPEC.md) and the README's *Access token* section.
